# Aplikasi Program Stok Barang 📦

Aplikasi sederhana untuk mencatat dan mengelola inventaris atau stok barang masuk dan keluar. Proyek ini dibuat untuk membantu memantau ketersediaan barang dengan mudah.

## 🚀 Fitur Utama
- Menambah jenis barang baru ke dalam sistem.
- Mencatat transaksi barang masuk (penambahan stok).
- Mencatat transaksi barang keluar (pengurangan stok disertai validasi agar stok tidak minus).
- Peringatan otomatis status stok (Aman, Menipis, atau Habis).

## 🛠️ Teknologi yang Digunakan
- Python (atau sesuaikan dengan bahasa yang Anda gunakan, misal: Excel / Google Sheets)
